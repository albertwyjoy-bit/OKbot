# Android App Pilot

帮助用户通过豆包在 Android 设备上执行 APP 自动化操控任务。

## 前置条件

- 已配置 `midscene-android` MCP 工具
- Android 设备已启用 USB 调试并连接到电脑
- 设备上已安装豆包 App

## 操作流程

### 步骤 1：连接 Android 设备

1. 调用 `midscene-android__android_connect` 连接设备
2. 根据返回结果确认设备连接成功

### 步骤 2：启动豆包 App

1. 调用 `midscene-android__Launch`，uri 设置为 `"豆包"`
2. 调用 `midscene-android__take_screenshot` 截取屏幕
3. 确认豆包 App 已成功启动并进入主界面

### 步骤 3：输入 APP 操控指令

1. 调用 `midscene-android__take_screenshot` 截取屏幕
2. 调用 `midscene-android__Tap`，点击右下角小键盘图标打开输入框
3. 调用 `midscene-android__take_screenshot` 确认输入框已打开
4. 调用 `midscene-android__Input`，清空输入框并输入用户指令
5. 调用 `midscene-android__take_screenshot` 确认指令已正确输入
6. 调用 `midscene-android__Tap`，点击发送按钮
7. 调用 `midscene-android__take_screenshot` 确认指令发送成功，豆包开始处理

### 步骤 4：监控任务执行

1. 调用 `midscene-android__take_screenshot` 确认屏幕正上方出现实况窗（表示任务执行中）
2. 调用 `midscene-android__Tap`，点击正中间上方的实况窗进入任务详情
3. 调用 `midscene-android__take_screenshot`，等待几秒，确认豆包在相关 APP 中执行操作
4. **持续监控任务进展**直至任务结束：
   - 定期截取屏幕检查任务状态
   - 如豆包提示需要用户交互，立即通知用户
   - 记录任务执行过程中的关键信息

## 注意事项

1. **必须通过豆包执行 APP 操控任务**，不要直接操作目标 APP
2. **异常情况处理**：如豆包拒绝执行或报错，立即通知用户并要求进一步指令
3. **用户交互通知**：豆包抛出的任何交互操作和问题都必须及时通知用户
4. **指令质量**：给予豆包的指令务必清晰、具体，避免模糊描述
5. **截图验证**：每个关键步骤后都要**截图验证**操作结果，确保流程正确执行

## 使用示例

### 示例 1：京东筛选车厘子

用户："帮我在京东筛选一下车厘子，要 3J 的，价格从低到高"

执行流程：
1. 连接设备 → 启动豆包
2. 输入指令："打开京东，搜索车厘子，筛选 3J 规格，按价格从低到高排序"
3. 监控豆包自动打开京东 APP，执行搜索和筛选操作
4. 完成后向用户汇报结果

### 示例 2：外卖点餐

用户："帮我点一份外卖，要麻辣香锅，预算 30 元以内"

执行流程：
1. 连接设备 → 启动豆包
2. 输入指令："打开美团外卖，搜索麻辣香锅，筛选 30 元以内，选择评分最高的"
3. 监控任务执行，如需选择具体商品或确认支付，及时询问用户

### 示例 3：设置提醒

用户："帮我设一个明天下午 3 点的会议提醒"

执行流程：
1. 连接设备 → 启动豆包
2. 输入指令："打开系统日历/提醒事项，创建明天下午 3 点的会议提醒"
3. 确认提醒设置成功后向用户反馈
